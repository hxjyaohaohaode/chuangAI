# 语文教师内容验收清单

> 适用范围：每首诗、每套题、每份教案和每次大模型提示词升级。技术测试通过不代表学科内容正确；上线或参赛演示前须由具备小学语文教学经验的人员复核。

## 一、事实与版本

- [ ] 诗题、作者、朝代、原文、标点与教材版本一致。
- [ ] 注音、多音字、通假字、异文和注释来源可追溯。
- [ ] 译文未过度现代化，文化常识、典故和时代背景无事实错误。
- [ ] 对存在学术争议的解释注明“常见解释 / 另一种观点”，不伪装成唯一结论。
- [ ] 引用、图片、音频和字体的来源及许可已登记。

## 二、教学目标与命题

- [ ] 教学目标符合年级认知水平，并覆盖知识、能力与文化体验。
- [ ] 题目与教学目标一一对应，难度梯度合理。
- [ ] 选择题只有一个最佳答案；干扰项错误原因明确。
- [ ] 主观题评分量规包含关键点、允许的合理异答和部分分规则。
- [ ] 不用生僻术语、歧义表述或超出学生经验范围的无关情境制造难度。
- [ ] 分层题并非给低层学生贴标签，教师可以人工调整与拒绝建议。

## 三、AI 输出安全与可控性

- [ ] 所有 AI 结果显著标注来源和生成状态。
- [ ] 教师可修改、拒绝、重生成，且修改记录可追溯。
- [ ] 原始学生作品不会被生成结果覆盖。
- [ ] 对事实不确定、证据不足或模型失败的情况明确降级，不编造答案。
- [ ] 未出现政治、宗教、性别、地域、民族、残障或家庭背景偏见。
- [ ] 学生个人数据最小化采集，展示和导出均已匿名化。

## 四、课堂可用性

- [ ] 教师首次进入后能在 3 分钟内完成“选诗—备课—发布”。
- [ ] 课堂核心操作不依赖记忆复杂路径，按钮名称与教学语言一致。
- [ ] 弱网、断网、模型超时、音频失败时仍可继续授课。
- [ ] 大屏、教师电脑、平板与手机的关键信息均可辨认。
- [ ] 键盘导航、焦点、对比度、字号与 reduced motion 可用。
- [ ] 每项错误都有可理解提示、恢复动作和人工接管入口。

## 六、放行条件

以下任一项未满足则不得对外宣称“内容已验证”：

1. P0 / P1 学科事实错误为 0；
2. 每套题的答案和评分量规已人工复核；
3. 高风险 AI 生成路径完成至少一次失败演练；
4. 真实试点结果与 DEMO 数据在界面和材料中严格分离；
5. 验收人签字且复验结论为“通过”。
6. 对外宣称的教材核心数量等于逐首溯源审计中 `VERIFIED + TEXTBOOK_CORE` 的实际数量，不使用历史注释中的 112/132/134 等混合口径。
