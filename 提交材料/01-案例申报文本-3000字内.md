# 诗脉·启明：小学古诗词“教—学—评—创”异构多智能体系统

## 案例概述

小学古诗词教学常面临三类断层：教师备课资料分散、课堂难以同时照顾不同认知层次、课后批改只能看到对错而难以定位原因。诗脉·启明以教师为最终决策者，把备课、分层命题、课堂互动、多模态批改、六阶诊断、个性化干预和创作再迭代连接成一条可追溯闭环。

## AI 如何解决真实问题

系统以布鲁姆六阶认知模型和古诗词知识图谱为教学骨架，由不同专长的智能体协作：诗心负责学情诊断，诗眼负责图像与朗读识别，诗笔负责命题、批改与创作反馈，编排官负责计划拆分、执行观测和教师介入。DeepSeek 用于深度推理与结构化生成，MiMo 用于多模态、语音和快速任务；所有 AI 结果均标注来源，教师可以复核、修改、拒绝或重新生成。

备课时，教师可按年级、诗篇和目标生成分层教案与六阶题目；课堂中，导播台依据实时作答提供换题、提示、虚拟对手和节奏建议；课后，系统识别手写答题与朗读音频，形成学生画像、知识缺口、学习路径和个性化处方；在创作迭代台，教师可按真实诗篇、年级和类型发布创造任务，学生作品经过多维反馈后保留原作，再形成可比较的新版本。教师的修正被记录为可审计反馈，用于后续 Prompt 版本与 A/B 评估，而不是让系统无约束自我修改。

## 易用性与可靠性

系统提供教师熟悉的驾驶舱式界面，覆盖桌面与移动端，并为加载、空数据、失败、离线和 reduced motion 提供明确状态。网络或模型不可用时，系统依次降级到已保存结果、本地知识与规则化演示，绝不把规则结果伪装成 AI。诗库单点失败时，内置诗篇会常驻标识为仅供预览，并阻断真实命题直至教师重试成功；AI 副驾的学生/诗篇物料在正式模式只使用后端返回的脱敏或真实数据，单点失败不静默换成演示物料；DEMO 数据不作为真实学生数据或效果证据。

项目已完成生产构建和系统化验证：前端 210 条 API 调用与后端 219 个端点全部完成路径/方法契约审计，0 缺失路径、0 方法错配；218 条 HTTP 端点完成分层运行时验证，其中 210 条主业务路由无 5xx/栈泄漏，5 条长期记忆与 3 条认证端点完成专项生命周期测试；未认证 WebSocket 被拒绝，认证后握手与心跳正常；关键后端测试范围共 616 项通过，行覆盖率 97.49%；Fastify 生产同源托管下 32 个桌面/移动界面组合最终 0 警告、0 失败；报告历史使用具名原生操作，键盘查看后焦点交给新报告标题，移动端单屏保留标题、状态、时间和操作而不横向滚动；答题图片堆使用原生按钮，大图预览具备 Enter、正反向 Tab、Escape 回焦和移动端无裁切契约，媒体资源中止时卡片和大图均明确显示“图片暂不可用”而非空白；星图沉浸导航关闭时完全退出对话框语义与焦点序列，遮罩关闭回到菜单触发点；空通知面板在无内部控件时仍接收焦点、约束正反向 Tab、Escape 回铃铛，并在窄屏按视口锚定避免裁切；命令面板以 Ctrl/Cmd+K 打开时聚焦关联结果的组合框，方向键保持唯一活动项，关闭直接卸载仍回来源控件，并在窄屏保持可用宽度；文化语境将未完成的原文双信源/教师验收默认展开，明确区分篇目范围、来源登记与仍待教师复核的 AI 教学内容，不把 0/148 未验收诗篇说成教材已验证；诗词接龙的起始诗篇下拉框具备显式名称，真实诗库故障恢复后才重新启用；思考链按钮保留经后端长度约束后的完整问题作为可访问名称，避免同前缀推理记录无法区分；进化之眼在没有持久化证据时不伪造版本或 A/B 结果，也不下载无意义 3D 分包；模式按 Agent 隔离归因，有证据时只定位到仍存在的最新关联版本，详情中的 Agent 标识在可容纳时完整显示，紧凑卡片和图表对超长标识显式显示省略号，查看关联版本动作保留完整长模式名，失效边明确披露且不提供虚假跳转；其真实多选来源筛选支持 Home/End，具名删除 chip 保持键盘可达、至少 24px 且窄屏不溢出；共享富文本与球面图库图片在资源失败时明确披露、禁用误导入口或重载，不把破图伪装为加载完成；AI 副驾本地图片附件在缩略图解码失败时明确提示、从下一次模型请求排除，教师仍可发送纯文字并在窄屏移除重选；跟读录音正常停止等待最终音频块且仅提交一次，迟到授权或模块卸载会回收设备并取消提交；该录音检查只覆盖前端媒体与请求边界，不宣称真实发音或识别效果；首屏真实 gzip 93,718B，满足 120KB 预算。

## 创新与开源

创新点不是增加一个聊天框，而是把“六阶认知诊断、知识图谱、异构多智能体、教师反馈进化”组成可运行的教学闭环。项目提供开源许可证、安装/使用文档、第三方声明与引用矩阵，便于学校本地部署和二次开发。数据默认保存在本机 SQLite，学生导出数据使用匿名名，上传文件具备类型、大小、解码和路径安全限制。
