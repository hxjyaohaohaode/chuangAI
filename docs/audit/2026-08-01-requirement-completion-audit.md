## 4. 系统优化

状态：**本轮确定的工程优化已实现并回归**。

- 安全：回环部署边界、上传魔数/解码/总量限制、路径约束、原子凭据写入、弱口令失败关闭、生产 sourcemap 关闭；全部 `/api` 与生成媒体响应统一为 `private, no-store`，生成 WebP 未认证读取 401、有效会话读取 200；ASR 中间音频与元数据执行 10 分钟成对清理，文件删除失败时保留元数据供重试，且清理路径被约束在朗读音频目录；MiMo ASR 客户端底层只接受受控 Buffer/base64，拒绝 URL 代取；朗诵评分只接受标准化受保护媒体引用，TTS 音色名与媒体读取/删除均执行路径安全白名单；批改图片预览、模型编码和删除对持久化路径执行目录结构、文件名/MIME 与 `realpath` 四重校验；OCR 只接受魔数匹配的内联图片，生图落盘只下载 DashScope HTTPS OSS 白名单地址；生产同源 E2E 实测 CSP、HSTS、点击劫持、MIME 嗅探与 Referrer Policy；Permissions-Policy 只允许同源麦克风并关闭产品未使用的摄像头、屏幕采集、定位、支付和硬件总线权限。
- 模型图片边界：通用 AI 对话只接受魔数匹配的 user 内联 JPEG/PNG/WebP，按单图、总量和请求体三层限制资源；MiMo 客户端在 SDK 前统一拒绝任意外链，只保留内联魔数图片和 DashScope OSS 白名单生图链路。
- 凭据与远端响应边界：DeepSeek、MiMo、DashScope 端点只允许官方 HTTPS 主机、标准端口和精确路径，环境解析在启动前失败关闭；创作任务持久化图片只允许系统受保护生成 WebP，任意外部追踪地址在任务查询、SQLite 写入和广播前被拒绝。生图下载禁止自动 30x，独立限制 30 秒、20MiB、三类 MIME/魔数和 2,500 万解码像素，chunked 响应超限即取消；TTS 远端音频按 MP3/WAV/Opus 分别限制 MIME、魔数和 24/64MiB 字节；设置连通性错误正文限 64KiB、Wan JSON 限 1MiB/JSON MIME，响应体消费纳入完整超时，接口均拒绝重定向，错误详情返回前移除当前密钥、常见令牌和 PII。
- 缓存崩溃一致性：生图同键并发经单航班合并，失败可重试；WebP/索引同目录临时写入、刷盘后原子替换，不同键完成时重读并合并最新索引，防止重复扣费、半文件和并发丢记录。
- 真实性：AI / 规则 / DEMO / 真实数据分层标识，演示样例不再作为教学成效，原始作品不被生成版本覆盖；AI 副驾正式学生物料只使用后端匿名名，学生/诗库局部故障不会静默替换为演示上下文，内置知识点明确为提示词参考。
