# 静态风险标记分级说明

生成日期：2026-08-01；2026-08-09 按最新源码台账复核

## 严格基线

全仓 AST/文本审计覆盖 558 个产品源码文件、245,429 行、9,131 个函数。当前启发式标记 528 项：非空断言 251、CSS `!important` 180、console 74、TODO 9、localhost/回环默认值或安全测试探针 12、危险 HTML 关键词 1、疑似密钥 1。

这些是“审查入口”，不是已确认缺陷数量。旧版正则曾只识别 `foo!.bar`，漏掉 `array[i]!`；现已改成 TypeScript AST `NonNullExpression`，并把注释中的 `any` 排除，避免同时漏报和误报。

## 非空断言

- 251 项中，145 项位于测试、2 项位于开发回放器、104 项位于生产代码。
- 本轮累计移除 38 个面向可变外部状态的断言：React 根节点、异步班级列表、Canvas context、随机换题候选、并行文化段落、批改结果竞态、空进化版本/模式、报告空集合、模型消息、调度器节点、主动预警与可选检索条件等均改为显式守卫或降级。
- 剩余生产项主要位于固定非空配置数组、DP/图布局循环、长度检查后的数组首项、Map 先初始化后读取、正则匹配成功分支。它们仍保留在机器清单中，不被描述成“零风险”。
- 后续收敛优先级：外部 API/数据库数组 > DOM/WebGL 能力 > 随机/并发状态 > 固定常量与数学不变量。禁止为了数字清零而引入重复分支或掩盖真实 invariant。

## 证据边界

静态读取和哈希证明每个文件进入了机器审计，不能证明每行语义绝对无错。语义可信度来自类型检查、关键范围覆盖率、HTTP/WebSocket 冒烟、闭环回归、浏览器交互回归与人工视觉检查的交叉证据。

静态源码标记也不替代供应链与发布边界审计。最新独立证据为：npm 官方注册表生产依赖需修复 0、条件跟踪 0；此前的 `fast-uri` 与 `brace-expansion` 高危传递依赖已通过 pnpm override 升级到修复版本并重新安装验证。审计器会对任何未来公告的实际模块与修复范围查询官方 registry，避免把父包版本或未发布版本误写成可执行升级方案；架构或公告变化时必须重审。发布候选疑似密钥命中 0、链接 0，本地 `.env`/日志/数据库等 51 个文件必须由白名单打包器排除。

## 记忆治理专项标记

长期记忆已有独立教师治理面。2026-08-04 认证边界升级后，顶层 `teacherId` 不再由调用方决定，而由 Fastify 签名 HttpOnly 会话绑定；教师/学生记忆的列表、修改、删除、批量清理按 ownerId 与班级/学生关系收敛。学生记忆必须绑定班级，未明确班级的 studentId 查询/批量删除失败关闭；智能体内部记忆只能归属 `system`；正文和标签拒绝手机号、身份证、电子邮箱和访问密钥等直接标识符；持久化记录有保留期、容量上限、过期清理和不可信上下文转义。当前边界只证明单教师本地租户隔离，不等于学校多租户身份平台；公网或多教师部署仍须先补齐 tenant 主数据、对象授权与部署安全门禁。
