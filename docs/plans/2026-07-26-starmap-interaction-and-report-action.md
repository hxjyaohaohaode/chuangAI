# 星图交互与报告行动台优化记录

## 目标

- 消除诗境球面点击时的纹理重载、画面卡顿与选中后停止自转。
- 让界面真实展示关系，同时避免 10,343 条边全部上屏形成线团。
- 将报告页的家校联系本替换为与教研报告直接相关的行动功能。
- 将核心业务页面的旧诗篇 SVG 插画入口升级为无水印 WebP。

## 关键决策

1. 球面 148 张图片按诗篇 ID 固定排序，选择、搜索和关系镜头不再改变纹理数组。
2. 选择节点只更新详情和局部关系，不再通过 React `key` 重建 Three.js 场景。
3. 关系轨迹只展示当前或选中诗篇到最多 5 篇真实关联诗篇；支持直接诗篇关系，也支持经诗人、时代、主题、意象、修辞节点推导的两跳关系。
4. 关系轨迹使用球面节点的实时屏幕投影绘制，选中后继续随球面旋转。
5. 报告行动台只消费 `ReportRecord` 已有的建议、发现、验收、暗点和脱敏样本字段，不新增伪数据接口。
6. 保留旧家校接口与组件文件以避免破坏其他潜在调用，但从报告页主流程彻底移除。
7. 旧 SVG URL 在统一图片组件中映射到内容对应的本地无水印 WebP；加载失败时显示语义化空态，不再回退低质量插画。

## 验收结果

- TypeScript lint：通过。
- Vite production build：通过。
- 图谱接口：924 节点、148 诗篇、10,343 原始边，诗篇 ID 无重复。
- 图片审计：148 manifest、148 文件、148 唯一 URL、148 唯一 SHA-256，覆盖 148/148 诗篇。
- 浏览器实测：连续点击《题临安邸》《菩萨蛮·书江西造口壁》均打开对应详情；canvas 始终为 1；选中后关系轨迹坐标持续变化；稳定后 60 FPS；控制台无错误。
- 报告页实测：教学改进行动台可见，家校联系本文案为 0，旧 SVG 图片为 0。

## 点击轻特写补充

- 点击诗篇后，使用增量四元数将目标图片平滑转到镜头正前方。
- 镜头只推进约 5%，目标图片放大 24%；其余图片保留原有空间位置并降低透明度。
- 特写期间停止自动漂移，但不销毁场景；关闭详情后从当前姿态继续自由旋转。
- 浏览器连续验证《题临安邸》与《菩萨蛮·书江西造口壁》均聚焦正确，canvas 始终为 1，稳定 60 FPS，控制台无错误。

### 聚焦流畅度修正

- 将每帧重复求解目标四元数改为选中时单次求解，使用 680ms 时间曲线完成旋转与镜头同步插值。
- 复用向量、四元数与图片索引映射，移除动画热路径中的查找和临时对象分配。
- 聚焦期间冻结前景节点切换并暂隐关系轨迹，避免连续触发 React 重渲染；结束后一次性恢复投影。
- 实测修正前聚焦瞬间约 3 FPS，修正后聚焦完成为 60 FPS，点击后的页面状态读取不再超时。
