# 诗脉星图沉浸式宇宙设计

## 目标

把诗脉星图从“侧栏 + 小型图表窗口”重构为可探索的全视口诗歌宇宙。3D 是唯一主可视化；列表只承担检索、低性能设备和无障碍降级，不再提供 2D 力导向视图。

## 体验架构

- 星图使用沉浸式应用外壳，占据浏览器可用视口。
- 左侧“观星舱”以浮动抽屉形式按需打开，承载搜索、类型筛选、着色模式、节点目录和图例。
- 顶部“星图航标”只显示标题、当前关系透镜和经过明确命名的数据口径。
- 关系透镜浮在画布顶部，可切换人物时代、意象、主题、修辞、诗篇共鸣与全部诗脉。
- 右侧“星体档案”只在选择节点后出现，不改变画布尺寸。
- 班级掌握度只出现在诗篇档案内；没有真实数据时明确显示空态，不生成推测分数。

## 空间语义

- 朝代沿时间轴形成贯穿空间的“诗史星河”。
- 诗人围绕所属朝代形成星系核心。
- 诗篇沿作者轨道分布，保持作品与作者的空间邻近。
- 意象、主题、修辞以关联诗篇的质心为基准形成跨星系云带。
- 节点使用确定性轻微漂移与呼吸反馈，避免每次进入时随机跳变。
- 双击节点进入两跳局部宇宙；退出后恢复当前透镜的全景。

## 数据口径

- “全库”使用加载并完成显式关系补齐后的完整数据。
- “当前视野”严格等于当前类型筛选、关系透镜和局部聚焦共同决定的实际渲染节点。
- “关系轨道”严格等于实际传入 3D 边渲染器的边数量。
- 原始 148 首诗和 63 位诗人必须通过独立审计脚本验证；同时验证悬空边、重复节点和重复边。
- 展示层可以为可读性裁剪高密度推断边，但不删除或篡改全库数据，并在界面中明确区分全库与当前视野。

## 降级与验证

- WebGL 不可用或 3D 渲染异常时切换到列表视图，不再回退到已删除的 2D 图。
- 保留减少动效、键盘操作、焦点样式和语义标签。
- 验收包含 TypeScript 检查、生产构建、数据审计、桌面与移动端截图、控制舱/透镜/节点档案/局部宇宙交互。
