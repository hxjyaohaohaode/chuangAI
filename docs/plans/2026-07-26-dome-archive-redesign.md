# 诗脉星图 · Dome Archive 重构

## 目标

将旧的密集节点/连线式星图替换为全屏浅色诗境穹顶。核心不是装饰性借鉴，而是把优质素材库中 DomeGallery、InfiniteMenu 与 ImageTrail 的空间机制迁移为知识图谱交互。

## 交互模型

- 图谱经过关系透镜筛选后，穹顶仍保留完整 148 首诗；透镜、检索和选中状态只调整前景优先级，不移除其他诗篇。
- 图像以斐波那契球面均匀分布，并沿球面切线朝外，减少节点重叠。
- 鼠标可进行水平与大角度垂直拖拽；松手后保持阻尼惯性，运动速度同步影响图像横向拉伸。
- 仅射线命中的一张图进入悬停态，其余图像同时降权，避免密集区域群体响应。
- 最靠近镜头的节点驱动左右两侧的标题、朝代、作者和内容摘要；点击图像或中央按钮打开真实节点详情。
- 选中节点后，穹顶切换为直接诗境，并提供可验证的直接关系与关系证据。

## 视觉系统

- 全局使用宣纸白、暖灰、墨黑与矿金，保持浅色但避免普通卡片化后台观感。
- 主视图占满窗口；标题、统计、叙事、工具和关系透镜作为展览档案式外围界面，不再挤压穹顶。
- 148 首诗均使用 Wan2.7-Image 生成独立诗境位图，按诗篇 ID 一对一映射；主体验不再使用通用 SVG。
- 空白区域的鼠标图像回声仅作为低频反馈，拖拽期间自动关闭，不干扰主要交互。

## 数据口径

- `ARCHIVE`：完整节点库。
- `DOME`：当前实际进入穹顶的诗篇数，固定与完整诗篇库 148 一致。
- `FILTERED`：当前关系透镜筛选后的关系数。
- `RELATIONS`：显式字段补全后的可验证关系库。
- 详情面板、直接关系和关系证据全部使用同一份图谱数据，不使用独立展示假数据。
