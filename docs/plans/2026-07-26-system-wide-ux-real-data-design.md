# 诗脉·启明：全系统交互、布局与真实数据深化设计

## 目标

把系统从“功能可见”提升到“教学现场可持续使用”。本轮以四个可验收结果为准：

1. 关键任务在桌面、平板和移动宽度下均不溢出、不遮挡、不中断上下文。
2. 课堂导播台形成“开课核验 → 开课 → 学生作答 → AI 评分/反馈 → 教师干预 → 报告”的真实闭环。
3. 页面只展示可追溯的数据来源；本地数据库中的种子数据明确标识为样例数据，模型生成内容明确标识为 AI 生成。
4. 所有主要操作具备加载、成功、失败、空状态和键盘/触屏可达状态。

## 设计方向

### 全局视觉与交互

- 延续浅色纸张、暖白、墨色和克制金棕色的整体语义。
- 用层级、留白、柔和表面差异取代大量边框和装饰性 SVG。
- 复杂页面统一采用“页面锚点 / 主任务区 / 上下文侧轨”结构。
- Hover 只响应当前目标，不做大范围连锁反应；位移动画控制在 2px 内。
- 长列表采用渐隐边缘、明确选中态、键盘导航和稳定滚动位置。
- 尊重 `prefers-reduced-motion`，所有持续动画均可降级。

### 课堂导播台

- 开课前：真实班级、完整诗库、真实题库覆盖和开课可用性核验。
- 开课后：URL 固化到 `/classroom/:lessonId`，允许刷新恢复、分享和报告追溯。
- 顶部状态带：课堂模式、加入码、在线人数、课堂专用实时连接状态、控制轨开关。
- 主舞台：答题、讲解、共舞三种视图保持闯关上下文，不因切换丢失状态。
- 控制轨：桌面常驻且可收拢；窄屏进入主内容流，不再离屏或制造横向滚动。
- 单设备代录：姓名、答案、快捷提交、真实 AI 评分和分维度反馈完整可用。
- 数据来源：题库、数据库、模型生成和实时连接分别展示，不用“智能”一词掩盖失败或占位数据。

### 真实数据与 AI

- 运行环境以 `DEMO_MODE=false` 为前提。
- 教学实体数据来自后端数据库；无数据时展示可操作空状态，不自动伪造为真实数据。
- AI 任务由后端模型适配层发起；前端不保存密钥，不用本地定时器伪装 AI 响应。
- 所有模型输出展示生成状态、供应商可用状态和失败后的明确重试路径。
- 对仍需保留的本地种子数据，统一标注“样例”，并提供替换/导入真实数据的入口。

## 验收矩阵

- 视口：1440×900、1280×800、1024×768、390×844。
- 课堂：新建、URL 恢复、模式切换、学生作答、AI 评分、提示、讨论题、下一题、结束、报告。
- 数据：后端健康、数据库健康、模型凭据状态与最小真实调用。
- 稳定性：无横向溢出、无控制台错误、无重复 WebSocket 状态覆盖、无重复提交。
- 可访问性：Tab 顺序、焦点可见、按钮语义、表单标签、降低动画。
- 构建：TypeScript 检查、生产构建、关键路由浏览器烟测。

## 推进顺序

1. 课堂纵向切片，修复会话、连接、布局和真实 AI 闭环。
2. 抽取全局状态条、页面标题、空状态、侧轨与表单规范。
3. 逐页替换不可用入口、演示回退和布局缺陷。
4. 对关键路由重复执行视觉、功能、数据、性能和错误审计。
