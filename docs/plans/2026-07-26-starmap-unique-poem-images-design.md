# 星图诗篇唯一图片方案

## 不变量

- 图谱共有 148 首诗，必须存在 148 张可用图片。
- 映射键只使用图谱诗篇 ID；标题仅用于提示词和人工核对。
- 一张图片只能属于一个诗篇，禁止共享 URL、共享文件或随机回退。
- 缺图时节点不进入穹顶，不能使用其他诗图或通用 SVG 伪装成功。

## 生成与存储

- 使用项目已配置的阿里云百炼 Wan2.7-Image。
- 输入包括诗篇 ID、诗名、作者、朝代、全文和唯一构图种子。
- 原始 2048×1152 图片下载后长期缓存为高质量 1280px WebP。
- 星图另存 640px WebP，兼顾高分屏清晰度和 148 张纹理解码开销。
- 图片生成关闭供应商像素水印；生成来源、模型与提示词版本保存在清单元数据中。
- 生成脚本支持断点续跑和单图重试，路径为 `backend/scripts/generate-starmap-poem-images.mjs`。

## 唯一性与数据核验

- 每张图生成 16×16 灰度感知指纹；与已有图片距离过近时自动更换构图重试。
- 完成后同时检查诗篇 ID、URL、感知指纹、文件 SHA-256 和磁盘文件。
- 当前结果：148/148；唯一 URL 148；唯一感知指纹 148；唯一文件哈希 148；SVG 0；缺失 ID 0。

## 展示

- 穹顶默认展示完整 148 首诗。
- 搜索、关系透镜和选中状态只改变排序与前景内容，不删除其他诗篇。
- 自动旋转从每帧 `0.00055` 降至 `0.00012`，悬停时暂停。
- 球面半径、图块尺寸和 640px 纹理按照 148 节点重新配置。
